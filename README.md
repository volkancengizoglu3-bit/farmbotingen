# FarmBotInGen

Android automation project for MU Immortal farming workflows.

## Planned features

- Navigate to a saved farming spot by opening in-game chat and tapping the configured coordinate.
- Optional buff management based on configurable ATK and DEF thresholds.
- Return to the saved farming spot after buffing.
- Detect death/respawn and return to the saved farming spot.

## Development status

Initial project setup. Game-specific screen coordinates and reliable visual detection thresholds will be configured after the user confirms the in-game UI positions.

## Build

The Android project and GitHub Actions APK build workflow will be added in the next setup step.
